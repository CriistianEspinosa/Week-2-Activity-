# Algorithmic Thinking: Search Algorithm Comparison

This project is a Java program that experimentally compares two different algorithms (Linear Search and Binary Search) that solve the same problem: finding a specific target number within a sorted array. 

## Features
- Implements two correct search strategies: Linear Search and Binary Search.
- Measures the exact execution time (in seconds) and the number of operations performed.
- Runs experiments across 5 different input sizes (1,000, 5,000, 10,000, 50,000, and 100,000 records).
- Demonstrates the difference in computational complexity (O(N) for linear vs O(log N) for binary).
- Outputs formatted performance metrics directly to the console.

## How to run in Visual Studio Code
1. Make sure you have the **Extension Pack for Java** installed in VS Code.
2. Open the file `SearchComparison.java`.
3. Click the `Run` or `Debug` button that appears above the `main` method, or press `F5`.
4. The output of the time and operation measurements for both algorithms will be displayed in the terminal.
